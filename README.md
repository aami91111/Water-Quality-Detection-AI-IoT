# Water Quality Detection Using AI and IoT

## Project Overview
An AI and IoT-based system designed to monitor water quality parameters and assess potential environmental risks.

The system uses an ESP32 microcontroller and water quality sensors to collect measurements. The collected data can be analyzed using Python and displayed through an interactive web dashboard.

## Key Features
- Water temperature monitoring
- pH level measurement
- Turbidity detection
- Total Dissolved Solids (TDS) monitoring
- AI-based risk assessment
- Interactive dashboard for data visualization
- Sensor readings and environmental status indicators

## Technologies Used
- Python
- Arduino IDE
- ESP32
- HTML
- CSS
- JavaScript
- IoT Sensors
- Blynk IoT Platform

## Project Components
- Arduino code for sensor integration
- Python code for risk analysis
- Web dashboard for displaying sensor readings

## Project Goal
To develop an intelligent water quality monitoring system that combines IoT sensor data and AI-based analysis to support environmental monitoring and early risk identification.
